# 🔐 OTP Generator & Verification System

A simple and secure **OTP (One-Time Password) Generator and Verification System** built using **Python Flask, HTML, CSS, and JavaScript**.

The project simulates a phone-number OTP verification workflow without requiring any paid SMS service or external API.

---

## 📌 Overview

This project demonstrates how an OTP-based authentication system works:

```text
Enter Phone Number
        ↓
Python Generates OTP
        ↓
OTP Displayed / Simulated
        ↓
User Enters OTP
        ↓
OTP Verification
        ↓
      ✅ Verified
